# Портфолио Алексея

Статический сайт-портфолио на Astro. Страница включает описание, проекты, технологии, услуги и контактную форму, которая открывает подготовленное письмо в почтовом приложении.

## Запуск и проверка

```sh
npm ci
npm run dev
npm run check
npm run build
npm run preview
```

## Структура

- `src/data/portfolio.ts` — контакты, проекты, навыки и услуги.
- `src/pages/index.astro` — разметка страницы и интерактивное поведение.
- `src/styles/global.css` — оформление, темы и адаптивность.
- `src/assets/` — изображения и локальные шрифты.
- `public/assets/files/resume.pdf` — резюме.
- `research/` и `reference/` — локальные архивные материалы; они исключены из Git и публикации.

## GitHub Pages

Workflow `.github/workflows/deploy.yml` запускает `npm run check`, собирает сайт и публикует его при push в `main` или вручную через GitHub Actions. Astro получает домен и путь проекта автоматически из GitHub Pages. Для локальной разработки переменные `SITE_URL` и `BASE_PATH` не нужны.

## Размер и ресурсы

Сборка использует оптимизированные WebP-превью и портрет, отдельные SVG-иконки и локальные WOFF2-шрифты Inter с кириллицей и латиницей. Неиспользуемые старые PNG, общий иконочный шрифт и Devicon CSS исключены из публикации. Сторонний CDN для оформления не используется.
